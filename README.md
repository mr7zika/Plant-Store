</p>

## 🚀 مميزات المشروع الحالية
- **إدارة المنتجات والأقسام:** استعراض النباتات حسب الفئات مع توضيح حالة المخزون (In Stock / Out of Stock).
- **سلة الشراء الديناميكية:** دعم إضافة المنتجات مع صور مصغرة وروابط تفاعلية لتحويل العميل لصفحة المنتج مباشرة.
- **نظام الطلبات وإدارة المخزون:** 
  - حفظ تفاصيل الطلب (`orders`) وعناصره بدقة (`order_items`).
  - تحديث وإرجاع الكميات للمخزون تلقائياً عند إلغاء الطلب عبر `Eloquent Model Events`.
- **لوحة بروفايل العميل:** 
  - استعراض الطلبات السابقة مع الحالات (قيد الانتظار، مؤكد، ملغى، إلخ).
  - إمكانية إلغاء الطلبات المتاحة.
  - زر طباعة مخصص لتنسيق الفواتير في صفحة واحدة نظيفة وجاهزة للطباعة.

## 🛠️ التقنيات المستخدمة
- PHP / Laravel
- Blade Templates & JavaScript (Fetch API)
- MySQL / phpMyAdmin
- CSS / Responsive Design
